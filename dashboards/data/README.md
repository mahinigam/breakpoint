# Tableau Data Export

Generated by:

```bash
python -m src.decision.export_dashboard_data
```

Every file is derived from `reports/metrics.json`, `reports/policy.json`, and the
canonical CSV reports. Do not edit these files by hand; they are overwritten by
`make tableau`.

`manifest.json` is the source of truth for row counts, columns, generation time,
and environment. The build guide is
[`docs/TABLEAU_DASHBOARD_GUIDE.md`](../../docs/TABLEAU_DASHBOARD_GUIDE.md).

## Files

| File | Grain | Notes |
|---|---|---|
| `threshold_curve.csv` | scenario × cutoff | Profit, oracle profit, regret; 2,324 rows |
| `policy_markers.csv` | scenario × policy | F1, KS, top-4%, binary minimax, action cutoffs |
| `action_mix.csv` | scenario × action | Share, bad rate, margin, loss, exposure |
| `operating_characteristics.csv` | scenario | Binary vs action profit, expected loss, exposure |
| `score_histogram.csv` | score bin | Weighted good/bad counts and action band |
| `calibration.csv` | method × bin | Weighted reliability diagram |
| `sensitivity.csv` | cost ratio | Continuous economic sensitivity |
| `drift.csv` | feature | Top 50 features by PSI |
| `kpi.csv` | scenario | Headline KPI cards |
| `policy_card.csv` | policy | Cutoffs, guardrails, action multipliers |
| `bootstrap.csv` | scenario × comparison | Profit advantage, CI, p-value |
| `power.csv` | accounts per arm | Simulated power |

## Conventions

- `*_pct` columns are already multiplied by 100. A value of `6.8` means 6.8%.
- `*_millions` columns are in USD millions.
- `scenario_label` is title-cased for display; `scenario` is the stable key.
- `action` is lowercase (`grow`, `hold`, `restrict`); `action_label` is title-cased.
- `p_value = 0.0` means below the 1/1,000 bootstrap resolution; display `<0.001`.
- No customer-level rows, labels, or identifiers are present.
